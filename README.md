# tiktokbot

Telegram-бот: присылаешь ссылку на видео из TikTok, получаешь его обратно без водяного знака
в максимальном качестве. Видео приходит нативным сообщением, его можно сохранить в галерею
штатной кнопкой Telegram. Пересылки между людьми Telegram сжимает, а загрузки через Bot API нет,
поэтому файл доходит как есть.

Только видео и только личные чаты. Фото-посты и слайдшоу не поддерживаются.

## Как это работает

- aiogram 3 ловит ссылку в сообщении, yt-dlp достаёт список форматов.
- Берётся лучший формат без водяного знака. Обычно это 1080p в H.265.
- Если файл больше лимита Bot API в 50 МБ, бот берёт следующий формат по качеству, пока не влезет.
- HEVC-файлы с тегом `hev1` перемаркируются в `hvc1` через ffmpeg без перекодирования,
  иначе Фото на iPhone может показать чёрный экран.
- `file_id` отправленного видео кладётся в SQLite. Повторная ссылка отдаётся мгновенно.

## Запуск

Нужны Python 3.10+ и ffmpeg в `PATH`.

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN от @BotFather
python -m bot
```

Все настройки описаны в `.env.example`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты не ходят в сеть: селектор форматов проверяется на синтетическом наборе, ремукс на файле,
который собирает ffmpeg.

## Развёртывание на VPS

Подходит любой Ubuntu или Debian. Портов и домена не нужно, бот сам ходит в Telegram,
поэтому спокойно живёт на одной машине с VPN или чем угодно ещё.

Сначала проверь, что TikTok вообще отвечает с IP сервера. На сервере:

```bash
python3 -m venv /tmp/yt && /tmp/yt/bin/pip install -q yt-dlp && /tmp/yt/bin/yt-dlp -F "<любая ссылка на видео TikTok>"
```

Если вывелась таблица форматов, всё в порядке. Если ошибка, см. раздел ниже про прокси.

Установка:

```bash
git clone https://github.com/pisaevv/tiktokbot.git /opt/tiktokbot
```

```bash
cd /opt/tiktokbot && sudo bash deploy/install.sh
```

Скрипт поставит ffmpeg, создаст системного пользователя `tiktokbot`, venv, спросит токен,
включит systemd-сервис с автозапуском и перезапуском при падении и добавит в cron
еженедельное обновление yt-dlp. Кэш живёт в `/var/lib/tiktokbot/cache.sqlite3`.

Полезное:

```bash
journalctl -u tiktokbot -f
```

```bash
sudo /opt/tiktokbot/deploy/update.sh
```

## Эксплуатация

- yt-dlp ставится с дополнением `curl-cffi`, без него TikTok отвечает ошибкой
  «no impersonate target is available»: экстрактор маскируется под браузер.
- Экстрактор TikTok в yt-dlp ломается чаще остальных. Если бот начал отвечать «не получилось
  скачать», первым делом `pip install -U yt-dlp`.
- На VPS TikTok иногда режет датацентровые IP. Тогда в `.env` задаётся `YTDLP_PROXY`,
  прокси используется только для yt-dlp. Прокси должен быть на другом IP, иначе смысла нет.
- Ролики длиннее двух-трёх минут в 1080p могут не влезть в 50 МБ. Бот отдаст версию ниже.
  Если нужен максимум и для них, поднимается локальный `telegram-bot-api` с лимитом 2 ГБ
  и повышается `MAX_FILE_SIZE_MB`.
