# tiktokbot

Telegram-бот: присылаешь ссылку на видео из TikTok, получаешь его обратно без водяного знака
в максимальном качестве. Видео приходит нативным сообщением, его можно сохранить в галерею
штатной кнопкой Telegram. Пересылки между людьми Telegram сжимает, а загрузки через Bot API нет,
поэтому файл доходит как есть.

Только видео и только личные чаты. Фото-посты и слайдшоу не поддерживаются.

## Как это работает

- aiogram 3 ловит ссылку в сообщении, yt-dlp достаёт список форматов.
- Берётся лучший формат без водяного знака. Обычно это 1080p в H.265.
- Если файл больше лимита Bot API в 50 МБ, бот берёт следующий формат по качеству, пока не влезет.
- HEVC-файлы с тегом `hev1` перемаркируются в `hvc1` через ffmpeg без перекодирования,
  иначе Фото на iPhone может показать чёрный экран.
- `file_id` отправленного видео кладётся в SQLite. Повторная ссылка отдаётся мгновенно.

## Запуск

Нужны Python 3.11+ и ffmpeg в `PATH`.

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN от @BotFather
python -m bot
```

Все настройки описаны в `.env.example`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты не ходят в сеть: селектор форматов проверяется на синтетическом наборе, ремукс на файле,
который собирает ffmpeg.

## Эксплуатация

- Экстрактор TikTok в yt-dlp ломается чаще остальных. Если бот начал отвечать «не получилось
  скачать», первым делом `pip install -U yt-dlp`.
- На VPS TikTok иногда режет датацентровые IP. Тогда поможет прокси для yt-dlp или
  cookies из браузера.
- Ролики длиннее двух-трёх минут в 1080p могут не влезть в 50 МБ. Бот отдаст версию ниже.
  Если нужен максимум и для них, поднимается локальный `telegram-bot-api` с лимитом 2 ГБ
  и повышается `MAX_FILE_SIZE_MB`.
